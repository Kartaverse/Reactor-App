# Reactor App Development Repo

## Overview

Reactor is a package manager created by the [We Suck Less Community](https://www.steakunderwater.com/wesuckless/viewforum.php?f=32) for Fusion/Resolve, Houdini, and LightWave. Reactor streamlines the installation of 3rd party content through the use of "Atom" packages that are synced automatically with a Git repository.

The classic version of the Reactor Package Manager has been revamped as [Reactor Standalone](https://github.com/Kartaverse/Reactor-Standalone) a desktop application created in 2025 that works seamlessly on macOS, Windows, and Linux. 

![Xojo IDE](Docs/Images/xojo-reactor-project.png)

The last year of Reactor Standalone beta testing has helped inform the Reactor developers of the key usability and general performance issues that needed addressing. This feedback is in the process of being integrated into the Reactor ecosystem via the new IBC 2026 tradeshow announced effort called [Reactor-Anywhere](https://github.com/Kartaverse/Reactor-Anywhere), a Progressive Web App (PWA) based port of the Reactor Standalone application. Reactor-Anywhere runs from any web browser session on MACoS, Wi dows, Linux, and iOS (iPads).the

## Reactor Folder

With Reactor Standalone the "Reactor:" PathMap folder is created in your user account's home folder at:

    $HOME/Reactor/

This location is typically:

    /Users/<Your User Account>/Reactor/
